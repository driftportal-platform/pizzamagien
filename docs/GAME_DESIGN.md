# PizzaMagien – spildesign

**Målgruppe:** ca. 3–8 år. **Stil:** Original, farverig 2D-tegneseriestil. **Primært layout:** Vandret på tablet og mobil, med responsivt alternativ på små skærme.

## Spilforløb
Start → Fri leg eller Mit pizzeria → vælg og placér fyld → bag → server → ny pizza/næste kunde.

## Næste versioner
- Ægte træk-og-slip af ingredienser med touch.
- Interaktiv dej, sauce og ost.
- Rigtig ovnanimation og pizzaskærer.
- Individuelle tegneseriefigurer af Aya, Fraya, Willa, Loui og kaninen i separate assets.
- Offline-cache/service worker og bedre PWA-ikoner.
- Fælles lydbibliotek og optagede danske stemmer.
